# Backup erstellen und finden

Im Ordner `daten` liegen viele Dateien, darunter einige Konfigurationsdateien (`.conf`) in verschiedenen Unterordnern.

1. Erstelle eine Liste aller `.conf`-Dateien unterhalb von `daten` und speichere sie in `conf_liste.txt` (ein Pfad pro Zeile).
2. Packe den kompletten Ordner `daten` in das komprimierte Archiv `backup.tar.gz`.
3. Entpacke das Archiv zur Kontrolle in den Ordner `wiederhergestellt` (lege ihn vorher an).

Nützliche Befehle: `find`, `tar -czf`, `tar -tzf`, `tar -xzf ... -C ordner`, `mkdir`
